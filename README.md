## Deployment

The deployable site is at the repository root. For Hostinger Git deployment use:

- Branch: `main`
- Build command: none
- Output directory: repository root
- Deployment type: static

For manual upload, place `index.html`, `assets/` and `robots.txt` in `public_html`.
